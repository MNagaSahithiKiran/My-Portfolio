## 🌟 Key Highlights

- **Apple Glassmorphism UI**: Specular pink progress bar, glass cards, ambient background glows, and pink particle animations.
- **44 Verified Credentials & Certificates**: Interactive certification gallery complete with official document preview modal viewer.
- **MongoDB AI Data Journey**: Visual 5-step pipeline (*Basics* ➔ *Vector Search* ➔ *RAG* ➔ *AI Agents* ➔ *AI Data Strategy*).
- **Accredited Learning Modules**: Category filter tabs showcasing technical training from *thingQbator/NASSCOM*, *Microsoft/Azure*, *Coursera*, *Qualcomm*, and *Infosys Springboard*.
- **Interactive Experience & Projects**: Vertical timeline cards for internships (*SkillCraft Technology*, *SkillNexis*, *Cisco*, *Qskill*) and live GitHub repository showcases.

## 🚀 Quick Start & Installation

```bash
# 1. Clone the repository
git clone https://github.com/MNagaSahithiKiran/My-Portfolio.git
cd My-Portfolio

# 2. Install dependencies
npm install

# 3. Start local dev server
npm run dev
```

Visit `http://localhost:5173/` in your browser!

---

## 🛠️ Build for Production

```bash
npm run build
```

The compiled static site assets will be generated in the `dist/` directory.
